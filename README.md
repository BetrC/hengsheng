# 恒盛私享财富 · 专属理财顾问情绪操控终端

一个以中国股票/基金监控与 1 对 1 私人财富顾问交易终端为伪装的渐进式心理恐怖互动网站。

随着页面不断向下滚动，界面会从明亮专业的券商行情与贴心投顾对话，逐步异化为制造踏空焦虑、揭露情绪操控后台、暗室狂笑闭门喊单、洗脑托管契约与群眼凝视，最终在最底层进入全屏电影级碎屏高潮。

## 本地运行

- 直接双击打开 `index.html`，或使用任意静态文件服务器预览。
- 建议佩戴耳机并点击右上角「开启盘口音效」以获得完整的程序化 Web Audio 音景体验。

## 部署到 GitHub Pages

本仓库为纯静态站点（HTML + CSS + 原生 JS + Web Audio API），无需构建步骤：
- 在仓库 `Settings -> Pages` 中将 **Source** 设为 `Deploy from a branch`（选择 `main` / `/ (root)`）或 `GitHub Actions` 即可自动上线。
